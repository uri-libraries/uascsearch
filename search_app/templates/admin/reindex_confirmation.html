Reindex UASC XML Documents

⚠️ Important Notice

This operation will:

  • Clear all existing XML documents from the database
  • Re-download and re-index all XML files from URI web archives
  • Process hundreds of files, which may take 10-30 minutes
  • Temporarily affect search functionality during the process

📊 Current Status

The system will fetch the latest XML documents from the University Archives and Special Collections web archive, ensuring your search database contains the most up-to-date archival information.

🔄 Reindexing Process

  1. Clear existing database entries
  2. Fetch XML file list from URI web archives
  3. Download and parse each XML file
  4. Extract key fields (Title, Creator, Dates, Abstract)
  5. Store optimized content for fast searching

Note: The process runs in the background. You can continue using the admin interface while it completes.
